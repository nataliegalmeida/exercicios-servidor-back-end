# Exercícios de Servidor Back-End

Projeto criado para praticar conceitos básicos de desenvolvimento back-end utilizando **Node.js** e **Express**.

## Tecnologias

* Node.js
* Express
* JavaScript
* Git e GitHub

##  Exercícios

Neste projeto estou praticando:

* Criação de servidor com Node.js
* Utilização do Express
* Criação de rotas
* Funções para responder às requisições
* Uso de `request` e `response`
* Retorno de dados em JSON
* Arrays e objetos
* Parâmetros de rota
* Versionamento com Git e GitHub

## ▶️ Como executar

Instale as dependências:

```bash
npm install
```

Execute o servidor:

```bash
node servidor-mulheres.js
```

O servidor será executado na porta **3333**.


Este é um projeto de estudos desenvolvido durante minha jornada de aprendizado em desenvolvimento **Back-End**.
